Core Technology

Built on the best
open-source stack.

Winlator combines battle-tested emulation and compatibility layers to bring Windows gaming to ARM devices.

🍷
Wine
Windows compatibility layer that translates Windows API calls to POSIX. Enables running .exe, .msi and Windows software natively — no virtualization overhead.
📦
Box86 / Box64
x86 and x86_64 dynamic recompiler for ARM. Translates x86 instructions to ARM in real time, allowing 32-bit and 64-bit Windows binaries to execute on your Android device.
🎮
DXVK
Translates DirectX 9, 10 and 11 to Vulkan for near-native performance in hundreds of PC games.
⚡
VKD3D
DirectX 12 to Vulkan translation layer. Enables DX12 titles to run through the modern Vulkan graphics pipeline.
🖥️
Mesa — Turnip / Zink
Open-source Vulkan (Turnip) and OpenGL (Zink) drivers for Adreno GPUs with hardware acceleration.
🎯
Input Controls
50+ pre-built controller profiles for popular titles. Fully customizable on-screen touchpad and button mapping.
🔧
Containers
Isolated Windows environment containers. Run multiple configurations and games with different settings side by side.
🔊
Android ALSA
Custom ALSA audio module bridges Windows audio APIs to Android's audio subsystem for full sound support.
Getting Started

Up and running
in minutes.

No root required. Install the APK, launch, and your Windows environment is ready.

  • 1
    Download the APK
    Grab Winlator_11.0.apk from the GitHub Releases page. No Google Play required — just a direct APK install.
  • 2
    Allow Unknown Sources & Install
    Enable "Install from unknown sources" in your Android settings for your file manager or browser, then tap the APK to install.
  • 3
    Initial Setup
    Launch Winlator. The app will automatically download and configure Wine, Box64, and all required runtime components on first launch. This may take a few minutes.
  • 4
    Create a Container & Play
    Create a new container, install your Windows game or application, then launch it directly from the Winlator home screen with your desired settings profile.

Pro Tips

Get the most out
of Winlator.

Performance, compatibility and visual quality tips from the community.

⚡
Performance mode — Change the Box64 preset to Performance in Container Settings → Advanced Tab if you experience slowdowns.
🔷
.NET Framework apps — Install Wine Mono from Start Menu → System Tools → Installers for .NET-dependent applications.
🕹️
Old games compatibility — Add MESA_EXTENSION_MAX_YEAR=2003 as an environment variable in Container Settings for older titles that refuse to launch.
📌
Per-game shortcuts — Use the home screen shortcut for each game to define individual settings. Not all games need the same configuration.
🖼️
Fullscreen low-res games — Enable Force Fullscreen in shortcut settings to display low-resolution games correctly on modern high-DPI screens.
🎲
Unity Engine stability — For Unity games, switch Box64 preset to Stability or add the exec argument -force-gfx-direct in shortcut settings.
